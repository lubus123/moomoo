Key Parameters

Milk Producer Fat %, SNF %, production rate (constant → variable later)
Separator Target cream fat % → cream/skim split calculated from mass balance
Butter Plants Target butter fat %, powder type (NFDM/BMP/WMP), cream allocation split
Cheese Plants Cheese type (Cheddar/Mozz/Swiss/Parm), skim allocation split
Market Supply/demand curves per product, prices react to production volume
